# SG-Glaze-Nightshade-Mist
Schutz vor KI-Stilimitation: Glaze, Nightshade und Mist

- Experiment in Python (PyTorch, Hugging Face diffusers, GPU-Laufzeit in Google Colab): LoRA-Fine-Tuning von Stable Diffusion auf geschützten und ungeschützten Bildern
- Quantitative Auswertung mit PSNR, SSIM, LPIPS und CLIP sowie Robustheitstests gegenüber JPEG-Kompression, Skalierung und Rauschen
- Aufarbeitung von Diffusionsmodellen, latentem Raum und adversarialen Perturbationen; Einordnung in aktuelle Angriffsstudien und das EU-Urheberrecht (TDM-Schranke)
